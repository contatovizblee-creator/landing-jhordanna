# Landing Jhordanna

Landing page comercial estática, mobile-first e focada em conversão pelo WhatsApp.

## Estrutura

```
public/
├── index.html
├── style.css
├── script.js
└── assets/
    └── .gitkeep
```

## WhatsApp

O número ainda não foi informado. Quando estiver disponível, editar:

```js
// public/script.js
whatsappNumber: ""
```

Usar somente números, incluindo DDI + DDD + número.

## Cloudflare Pages

Configuração recomendada:

- Framework preset: None
- Production branch: main
- Build command: vazio
- Build output directory: public
